# Hashtagger

AI-powered hashtag generator for social media. Analyzes your posts in real time and suggests trending hashtags to maximize reach and engagement.

**Source:** [Loot Drop Startup Graveyard](https://www.loot-drop.io/ideas.html) — 1,388 upvotes

## Quick Start

```bash
# Backend
cd src && python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
python main.py

# Frontend
cd public && python -m http.server 3000
```
